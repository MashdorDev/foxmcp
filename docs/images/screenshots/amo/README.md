# Listing screenshots (addons.mozilla.org)

No text on the images, as Mozilla's listing guide asks; the captions go in each
screenshot's description field on AMO. Upload in this order:

1. `1-click-and-type.png`: The agent types into Wikipedia's search box in a normal tab. The orange border and the label show that an agent is working in the tab.
2. `2-snapshot.png`: content_snapshot lists a page's links, buttons and fields with refs; click and type use those refs.
3. `3-folder-upload.png`: A whole folder uploaded through the page's own Upload folder button, keeping its paths. No file dialog.

The captioned versions one level up are for the README and social posts.
